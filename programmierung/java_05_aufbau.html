1. Sprachelemente & Grundaufbau in Java

Theorie

F1 Was ist ein Bezeichner (Identifier) und welche Regeln gelten?

Ein Bezeichner ist ein von dir (dem Programmierer) frei gewählter Name, um Dinge in deinem Code zu benennen – zum Beispiel eine Variable (meinAlter), eine Methode (berechneSchaltjahr) oder eine Klasse (Auto).

Harte Regeln (ansonsten wirft der Compiler einen Fehler):
  • Darf nicht mit einer Zahl beginnen (123test ist verboten).
  • Darf keine Leerzeichen enthalten (nutze stattdessen mein_name oder meinName).
  • Darf kein reserviertes Schlüsselwort sein (du darfst eine Variable nicht public, int oder class nennen).
  • Erlaubte Zeichen sind Buchstaben (A-Z, a-z), Ziffern (0-9), der Unterstrich (_) und das Dollar-Zeichen ($).
  • Java ist Case-Sensitive (Groß-/Kleinschreibung ist wichtig: alter und Alter sind zwei verschiedene Dinge!).

F2 Wie wird Quellcode eingerückt und welchen Vorteil bietet das?

Unter Einrückung (Indentation) versteht man das Einrücken von Codezeilen nach rechts (meistens mit der Tab-Taste oder mit 4 Leerzeichen), sobald ein neuer Anweisungsblock (gekennzeichnet durch geschweifte Klammern { ... }) beginnt.

Der Vorteil: Dem Java-Compiler ist die Einrückung völlig egal. Für den Programmierer ist sie jedoch überlebenswichtig. Sie macht die hierarchische Struktur sichtbar. Wenn du eine if-Bedingung oder eine Schleife schreibst, siehst du durch die Einrückung auf einen Blick, welcher Code innerhalb der Bedingung ausgeführt wird und welcher Code erst danach kommt. Fehlerhafte oder fehlende Klammern lassen sich so viel schneller finden.

F3 Was ist ein Package?

Ein Package (Paket) ist ein physischer Unterordner in deinem Projekt, der zusammengehörende Java-Dateien gruppiert (z. B. alle Design-Dateien ins Package ui, alle Speicher-Funktionen ins Package database). Es sorgt für Ordnung und verhindert Namenskonflikte, falls du aus Versehen zwei gleichnamige Dateien erstellst.

F4 Was ist eine Klasse?

In der objektorientierten Programmierung (OOP) ist eine Klasse eine Art Bauplan oder Schablone. Die Klasse Auto beschreibt, welche Eigenschaften (Farbe, PS) und Funktionen (Fahren, Bremsen) ein Auto hat. In Java gilt der Grundsatz: Absolut jeder Code muss innerhalb einer Klasse stehen!

F5 Grundaufbau eines Java-Programms

Ein klassisches Java-Programm ist streng von außen nach innen (wie eine Matroschka-Puppe) aufgebaut:

  1. Package-Deklaration: Ganz oben steht (optional), in welchem Ordner die Datei liegt (package com.firma.projekt;).
  2. Imports: Darunter folgen Import-Befehle, um fremden Code oder Bibliotheken einzubinden (z. B. Scanner für Tastatureingaben).
  3. Die Klasse: Die äußere Hülle des eigenen Codes (public class MeinProgramm { ... }).
  4. Die Main-Methode: Innerhalb der Klasse braucht es einen fest definierten Einstiegspunkt (public static void main(String[] args)), an dem der Computer anfängt zu lesen.
  5. Anweisungen (Statements): Innerhalb der Main-Methode folgen dann die eigentlichen Befehle (Variablen anlegen, Berechnungen, Konsolenausgaben), die jeweils mit einem Semikolon ; enden.

💡 Wie funktioniert der Modulo-Operator (%)?

Der Modulo-Operator berechnet den Rest einer Division.
Beispiel: 10 % 3 = 1 (denn 10 geteilt durch 3 ist 3, Rest 1).
Wenn wir prüfen wollen, ob eine Zahl glatt durch 4 teilbar ist, rechnen wir jahr % 4 == 0. Kommt exakt Null heraus, wissen wir: Es gibt keinen Rest, die Zahl ist teilbar!

SchaltjahrPruefung.java Java 
package java_grundlagen;

public class SchaltjahrPruefung {

                    public static void main(String[] args) {
        
                    // 1. Variable anlegen (Wir prüfen das Jahr 2026)
                    int jahr = 2026;
                    boolean istSchaltjahr = false;
        
                    /* 
         * 2. Logik-Prüfung (Die Reihenfolge ist wichtig!)
         * Wir fangen mit der speziellsten "Ausnahme der Ausnahme" an.
         */
                    if (jahr % 400 == 0) {
                    // Ausnahme der Ausnahme: Durch 400 teilbar -> JA
            istSchaltjahr = true;
            
        } else if (jahr % 100 == 0) {
                    // Ausnahme: Durch 100 teilbar -> NEIN (z.B. das Jahr 1900)
            istSchaltjahr = false;
            
        } else if (jahr % 4 == 0) {
                    // Grundregel: Durch 4 teilbar -> JA
            istSchaltjahr = true;
            
        } else {
                    // Alle anderen Jahre -> NEIN
            istSchaltjahr = false;
        }

                    // 3. Ergebnis auf der Konsole ausgeben
                    if (istSchaltjahr) {
            System.out.println(jahr + " ist ein Schaltjahr.");
        } else {
            System.out.println(jahr + " ist KEIN Schaltjahr.");
        }
    }
}

Wenn du diesen Code in Eclipse startest, wird die Konsole ausgeben: "2026 ist KEIN Schaltjahr."

4. Standards: Die Java Naming Conventions

Best Practices

Wie in Aufgabe 1 (Bezeichner) besprochen, gibt es harte Regeln vom Compiler. Zusätzlich gibt es aber auch sogenannte Naming Conventions (Benennungskonventionen). Das sind ungeschriebene Gesetze der Entwickler-Community. Hältst du dich nicht daran, läuft dein Code zwar, aber andere Programmierer (und Prüfer) werden ihn als extrem unprofessionell einstufen:

Klassen in PascalCase

Klassennamen fangen immer mit einem Großbuchstaben an. Besteht der Name aus mehreren Wörtern, wird jedes neue Wort wieder großgeschrieben (ohne Leer- oder Unterstriche).

SchaltjahrPruefung, Auto, BankKonto

Variablen & Methoden in camelCase

Variablen und Methoden fangen immer klein an. Erst ab dem zweiten Wort wird der Anfangsbuchstabe großgeschrieben (sieht aus wie Höcker eines Kamels).

int meinAlter; public void berechneZinsen()

Konstanten in UPPER_SNAKE_CASE

Werte, die sich während der Laufzeit nie wieder ändern dürfen (Konstanten, in Java mit final markiert), werden komplett großgeschrieben und mit Unterstrichen getrennt.

final double PI_WERT = 3.1415;

Packages komplett klein

Paketnamen werden konsequent komplett kleingeschrieben, um sie von Klassen auf den ersten Blick unterscheiden zu können.

package de.firma.projekt;
